# Recover Auto

Read this after context loss or when Auto encounters existing state. Resolve this reference from the installed Auto skill's directory, not from a presumed path in the user's project.

1. Resolve the current project/worktree root using [state](state.md). If it has no `.jwn/`, finish without creating state or starting Auto.
2. Read `status.json` and `progress.jsonl`. Validate Auto ownership and task identity before resuming. A different task or another active session's writer requires a user decision. Same-session compaction retains existing ownership and permissions. Do not search another worktree or select a task by recency.
3. Validate complete JSONL records with consecutive sequences starting at 1, each event's `seq` matching its nested `status.lastEventSeq`, and matching event/status timestamps. Surface malformed JSON, missing or duplicate sequences, partial trailing lines, and missing required files. Do not skip records or invent outcomes. If the snapshot is missing or malformed but the entire log is valid and clearly belongs to this task, reconstruct it from the final event's status. An empty log cannot reconstruct a task.
4. Compare the snapshot with its corresponding event and the final event. If the snapshot trails a valid log, restore the final event's status atomically. If it is ahead of the log or conflicts with its corresponding event, report the conflict before dependent work.
5. Read the current and approved alignment and plan documents referenced by the recovered status, deduplicating identical paths. Missing documents remain unresolved. A `null` reference means that document or approval has not been established. Review progress for actual decisions, unfinished attempts, evidence, and the next action.
6. Check the actual checkout, current files, and revision before reusing recorded verification. An unfinished attempt has no recorded result. Inspect what actually happened before retrying or marking it successful. Record the recovered state and next action using the state contract.
7. Resume only work already authorized by the recovered agreement, plan, and current user request. Preserve pending approvals and separate commit, push, PR, merge, and deploy permissions. Summarize the restored stage, blocker or pending decision, and next action before continuing.
