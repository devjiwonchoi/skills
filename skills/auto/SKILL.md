## Steps

1. Read [state](references/state.md) to initialize this root's `.jwn/` or [recover](references/recovery.md) existing work and continue from its recorded stage.
   - Adopt standalone Align/Plan documents and approvals. Start at the first unfinished stage, reusing unchanged, unconflicted approvals consistent with the current agreement.
2. Follow [Align](../plan/align/SKILL.md) with the versioned agreement path.
3. Follow [Plan](../plan/plan/SKILL.md) with the versioned plan path.
4. Follow [Execute](../execute/execute/SKILL.md) with the Auto task directory.
5. Follow [Ship](../ship/ship/SKILL.md) for authorized delivery.

Pass the task directory to each stage. Use the state contract to record stage changes, approvals, blockers, delivery outcomes, and the final state.
