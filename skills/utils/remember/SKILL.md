# Remember

Apply the correction first. Judge corrections, rejections, and directed frustration from conversation context, excluding quotes and unrelated profanity. Ask to remember only when they reveal a concrete lesson that will help in future tasks.

Keep only lessons that will help later: user preferences, key choices, mistakes, fixes, and good ways to check the work. Do not save raw logs, secrets, short-lived details, or guesses. Check existing memory first, update it instead of copying it, note where the lesson came from and how sure you are, and save it in a short form any agent can use.
